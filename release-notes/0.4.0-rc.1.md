## Install the offline VSIX

Use an isolated VS Code profile and disposable Markdown files for review. Download or copy the candidate bundle before disconnecting; installing the VSIX does not require Marketplace access.

1. Extract the bundle into a writable folder. Keep `binary-markdown-0.4.0.vsix` together with its `.sha256` and `.build-info.json` files and the candidate's review record.
2. From that folder on macOS, check the package with `shasum -a 256 --check binary-markdown-0.4.0.vsix.sha256`. Linux can use `sha256sum --check`; on Windows, compare `Get-FileHash .\binary-markdown-0.4.0.vsix -Algorithm SHA256` with the supplied checksum. The result must match.
3. In VS Code, choose **Extensions → … → Install from VSIX…**, select the package, and reload when prompted. Reopen a test Markdown file with **Binary Markdown**.
4. Run **Binary Markdown: Copy Build Information**. Confirm version `0.4.0`, the source commit recorded in the accompanying build-information file, and a clean source stamp. The version alone does not distinguish RC1 from a later candidate or release.

PDF testing still needs an installed Chrome, Chromium or Edge; DOCX and EPUB need installed Pandoc. These external tools are not bundled. See [export setup](../media/export-help.md#tools-and-settings). Use local document assets for offline testing.

To return to the official version, install its published VSIX in the same test profile and reload. The extension identifier is unchanged; preserve any test files or settings you want to retain. Follow the [build guide](../docs/building.md#inspect-and-install-the-output) for package identity and installation details.

## Human acceptance checklist

- Confirm the unset Full-toolbar and top-left export-label defaults, and preservation of explicit saved choices.
- Drag actual windows narrow and wide at 100% and 200% zoom. Check table placement, overflow, contextual rows, every table cell, document width, alignment and boundary indicators.
- Exercise Insert, underline, code-language search/order and equation source placement/wrapping. Check cancellation, selection, undo/redo, Source mode and save/reopen, including English, another supported locale and real IME input.
- Export PDF and DOCX with labels, totals and numbering independently enabled and disabled. Include empty/blank blocks, tabs, Unicode, wrapped logical lines, multiple blocks and multi-page code.
- Open and edit DOCX in the actual reader/version you intend to support. Test Enter, soft breaks, blank lines, copy/paste and save/reopen. Check underline in Word and an EPUB reader, and inspect PDF copying and reading order.

The [editor guide](../docs/editor-guide.md) and [export help](../media/export-help.md) define expected behavior. Record Pass, Fail or Not tested with the candidate commit/checksum, environment, reproduction steps and a small non-private document.

## Validation and remaining limits

Earlier integration results remain evidence for their recorded revisions and artifacts. RC1's accompanying review record identifies its own package and local checks; it does not substitute for required release CI or human acceptance. Shared editor behavior covers VS Code and Electron, while export remains limited to the supported local desktop VS Code hosts. A VSIX does not install the standalone desktop app.

DOCX numbering remains experimental: the native-paragraph representation, reader/version matrix, interactive edits, copying and spoken order need acceptance. Syntax highlighting is static after reader edits. The observed unnumbered DOCX footer pagination problem and PDF gutter-copying limits remain; review the [remaining acceptance items](../reports/validation/2026-09-20-editor-export-stack.md#remaining-acceptance-items) before sign-off.

Preserve each distributed candidate and its matching evidence. A replacement build receives a new candidate number. Official `0.4.0` publication follows the [release procedure](../docs/releases-and-support.md#maintainer-release-procedure) after acceptance and required validation; these prerelease notes are separate from the final `0.4.0.md` release notes.

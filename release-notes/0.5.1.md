# Binary Markdown 0.5.1

Binary Markdown 0.5.1 is a rapid update replacing the previous version's unstable table toolbar with a more stable, compact toolbar. It retains the editor views, command search, source-based Find and Replace, and code wrapping introduced in [0.5.0](0.5.0.md).

## An apology and why this update is urgent

We apologize for the disruption and the short notice. This was a very last-minute decision: further testing revealed instability in the previous version's table toolbar, so we replaced it with a more stable, compact toolbar and are preparing this rapid update. Thank you for your patience while we address these issues.

## Changed and fixed

- **Compact table controls.** The toolbar now centers on an active-cell coordinate chip, alignment buttons, and a permanent **More table actions** menu. Open the coordinate chip for row and column selectors; the More menu keeps insertion, deletion, and toolbar placement within reach.
- **Clearer table navigation and insertion.** Clickable row numbers and column letters navigate without editing the document. Four boundary **+** handles insert around the active cell when space permits; the same actions remain available in the More menu.
- **Distinct text selection.** A subtle active-row and active-column tint stays separate from the stronger selected-text highlight across all seven editor themes.

See [table operations](../docs/editor-guide.md#table-operations) for placement, narrow-pane behavior, and keyboard controls, and the [changelog](../CHANGELOG.md#051) for the version history.

## Compatibility and defaults

Use local desktop VS Code 1.85.0 or later. The extension remains `BinaryOutlook.binary-markdown`; existing settings and update continuity are retained. Full or Simple formatting mode and explicit table-toolbar placement preferences continue to apply. The Electron manifests also use `0.5.1`; this does not publish or validate standalone installers.

## Known limitations

The [0.5.0 limitations](0.5.0.md#known-limitations) still apply, including external writes that can replace unsaved edits, bounded Markdown compatibility, incomplete export-reader acceptance, and remaining physical-input and accessibility checks. This toolbar replacement does not establish that every window size, zoom level, or platform has been accepted.

## Installation and release validation

Follow the [VSIX installation instructions](../README.md#install), retain the checksum and build-information sidecar, and use **Binary Markdown: Copy Build Information** after reloading to confirm version `0.5.1` and the full source commit against the sidecar.

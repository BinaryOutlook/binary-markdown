# Project-supplied 01 / MD artwork

`BinaryMarkdown.png` is the maintainer-supplied approved artwork for the 0.2.0 identity. The original supplied bytes are preserved; no vector original or additional authorship is asserted.

The supplied artwork and derived icons use the project's [AGPL-3.0-or-later terms](../../NOTICE). Community builds and factual references may use the artwork under those terms. See [branding guidance](../../docs/branding.md) for clear attribution and distinction from official releases.

The committed extension PNG and desktop PNG/ICNS/ICO are derived using `python3 scripts/build-icons.py` on macOS. Normal extension packaging uses the committed PNG and needs neither macOS icon utilities nor this source asset.

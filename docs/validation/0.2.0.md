Status: integration candidate prepared for review; maintainer acceptance, merge to `main` and publication are pending. The [Validate VSIX workflow](../../.github/workflows/ci-vsix.yml) and final integration PR identify the current run and exact candidate source. This record does not turn a local build or passing subset into an official release.

## Scope and required evidence

| Gate | Required evidence |
| --- | --- |
| Source and identity | Clean identified source; full commit/tree; version 0.2.0; AGPL-3.0-or-later; approved artwork; stable extension/settings IDs |
| Build and package | Node from `.node-version`; locked dependencies; compile/lint; full npm audit; shipped notices and byte parity with compiled sources; no bundled native converter/browser |
| Unit and converter tests | All units with `EXPORT_REAL_TOOLS=1` and the candidate VSIX; no skipped real-tool/package cases |
| Browser regression | Full suite on macOS and Ubuntu; no retries or skips |
| Installed VSIX | Fresh local profiles on macOS and Ubuntu; source stamp, four formats, native/keyboard save, dependency changes, cancellation, naming, UI, immutable capture and offline HTML |
| Minimum VS Code | The same candidate installed in declared VS Code 1.85.0 on Ubuntu |
| Artifacts | Four frozen fixtures × four formats; unchanged source hashes, 2,260 markers accounted for, original image bytes or PDF raster pixels preserved, valid archives/XML |
| Human acceptance | Representative PDF and editable-document/ebook reader review; acknowledge disclosed initial-format/platform limits; maintainer reviews final PR and release draft |

No fixed product completion time is a gate. Tests use infrastructure watchdogs and actual progress stages; workload content and correctness remain the acceptance target. W-30's reference calibration is 35 pages, with larger native page counts permitted. Frozen input bytes and required markers remain unchanged.

## Acceptance boundaries

- Export remains experimental. HTML/PDF retain unsupported dollar-math/TOC/footnote source with explicit warnings; DOCX/EPUB prioritize editable structure over matching pagination. Detailed diagnostics remain English.
- Original export-branch Word/Apple Books checks and PDF page inspections are dated in [export validation](../export-validation.md). New container/marker checks do not imply a fresh human review in every target reader.
- Local desktop Ubuntu under Xvfb is a local extension-host test even when the machine is reached over SSH. Remote-SSH, web hosts, Windows export, other Linux distributions and Electron export are outside this evidence.
- The inherited desktop auto-publisher is archived. Electron source type-checking is separate from installer validation; desktop packages are not part of this release candidate.
- Draft-release promotion is tested through source/run/byte guards before merge. An actual `main` dispatch and public publication are later maintainer actions; no release has been created merely to test the publisher.

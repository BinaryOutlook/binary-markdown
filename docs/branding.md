# Branding and community builds

Binary Markdown uses the project-supplied `01 / MD` artwork introduced for 0.2.0.
The [approved source PNG](../assets/branding/BinaryMarkdown.png), its provenance,
and regeneration instructions are in [the artwork record](../assets/branding/README.md).
A supplied PNG is the available source; no editable vector original is claimed.

The source artwork and derived icons are distributed under the project's
[AGPL-3.0-or-later terms](../NOTICE). Community builds and factual references may
use this artwork under those terms. Contributors retain their applicable rights.

Identify redistributed community builds as community builds, state the source
revision and relevant modifications, and avoid implying that BinaryOutlook
published or validated them. This identity guidance does not remove permissions
provided by the applicable copyright license or assert a registered trademark.

The extension ID stays `BinaryOutlook.binary-markdown`; the logo change does not
create a new extension or reset its settings. Official releases are those
published by the maintainer through the channels described in
[releases and support](releases-and-support.md).

The inherited upstream icon remains part of the historical Git record. The
current artwork replaces it without changing attribution for the original
Any Markdown editor and contributors.

Binary Markdown Editor

Write visually. Keep your Markdown. A visual editor for VS Code with reliable multiline code copying and an outline that remembers your preference.

Install a release

Choose a package from GitHub Releases. Read that release's notes for its source revision, tested platforms and limitations, and verify its checksum before installation.

  1. Open VS Code's Extensions panel and choose Install from VSIX….
  2. Select the package, then open a Markdown document.
  3. Choose Reopen Editor With… → Binary Markdown.

Installation leaves your default Markdown editor unchanged. Binary Markdown uses its own extension ID, commands, settings, and editor registration.

Built on a capable editor

Visual and source editing, tables, lists, code blocks, Mermaid diagrams, KaTeX math, themes, and translations are inherited from Any Markdown. Binary Markdown adds fixes for multiline code copying, configurable outline defaults, and remembered outline visibility.

Released in 0.4.0

Version 0.4.0 adds an Insert menu, underline, responsive table controls, configurable editor width and alignment, searchable code languages, and equation-source placement and wrapping. Experimental PDF and Word export gain configurable code labels, line counts, and numbering.

Read the published 0.4.0 release for its source revision, validated package, and known limitations. DOCX numbering remains experimental, and target-reader checks remain incomplete.

Changed and fixed in 0.4.1

Version 0.4.1 preserves paragraph structure and untouched table source, with aligned Markdown columns for new or edited tables. Fixes retain ordered-list starts and checklists, literal inline code, and the latest text during Save and Undo/Redo. Read the 0.4.1 release notes and changelog for the complete changes.

Available packages and their exact source, checksums and validation are listed on GitHub Releases. External writes can still replace unsaved local edits, and export-reader acceptance remains incomplete. The pre-release readiness record preserves the automated and human evidence and remaining issue recommendations.

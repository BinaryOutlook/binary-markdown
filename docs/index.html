Binary Markdown Editor

Write visually. Keep your Markdown. A visual editor for VS Code with reliable multiline code copying and an outline that remembers your preference.

Install a release

Choose a package from GitHub Releases. Read that release's notes for its source revision, tested platforms and limitations, and verify its checksum before installation.

  1. Open VS Code's Extensions panel and choose Install from VSIX….
  2. Select the package, then open a Markdown document.
  3. Choose Reopen Editor With… → Binary Markdown.

Installation leaves your default Markdown editor unchanged. Binary Markdown uses its own extension ID, commands, settings, and editor registration.

Built on a capable editor

Visual and source editing, tables, lists, code blocks, Mermaid diagrams, KaTeX math, themes, and translations are inherited from Any Markdown. Binary Markdown adds fixes for multiline code copying, configurable outline defaults, and remembered outline visibility.

Development toward 0.4.0

The upcoming version adds an Insert menu, underline, responsive table controls, configurable editor width and alignment, searchable code languages, and equation-source placement and wrapping. Experimental PDF and Word export gain configurable code labels, line counts, and numbering.

These changes are in release preparation. Check the changelog and each published release's notes for availability and known limitations. DOCX numbering and target-reader behavior still need acceptance checks.

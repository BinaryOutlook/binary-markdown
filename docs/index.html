Install a release

Install Binary Markdown Editor from the Visual Studio Marketplace in local desktop VS Code 1.85.0 or later.

  1. Open VS Code's Extensions panel and search for @id:BinaryOutlook.binary-markdown.
  2. Select Binary Markdown Editor by BinaryOutlook, choose Install, and reload if prompted.
  3. Open a Markdown document and choose Reopen Editor With… → Binary Markdown.

VS Code installs Marketplace updates when automatic extension updates are enabled. For manual updates, run Extensions: Check for Extension Updates, then select Update for Binary Markdown.

For offline installation or a specific version, download a VSIX and checksum from GitHub Releases, verify the checksum, and use Extensions → … → Install from VSIX…. Read the installation guide for details. Marketplace and GitHub versions can differ because publication is separate.

Installation leaves your default Markdown editor unchanged. Binary Markdown uses its own extension ID, commands, settings, and editor registration.

Built on a capable editor

Visual and source editing, tables, lists, code blocks, Mermaid diagrams, KaTeX math, themes, and translations are inherited from Any Markdown. Binary Markdown adds fixes for multiline code copying, configurable outline defaults, and remembered outline visibility.

Version 0.5.2

Version 0.5.2 keeps your unsaved edits when another program writes the open file. A warning offers Compare and Load Disk Version, and Undo restores edits replaced by loading. Settings now appear in ordered categories with their saved values unchanged, code-block buttons can show icons only, and the outline scrollbar follows the editor theme.

Read the 0.5.2 notes for what changes after updating and known limitations. Export-reader acceptance remains incomplete. GitHub Releases shows whether a version is published, with its source revision, checksums and validation.

Earlier versions

Version 0.5.1 replaced an unstable table toolbar with compact table controls. Version 0.5.0 added Visual, Source and Split views, source-based Find and Replace, searchable command workspaces, block diagnostics and per-block code wrapping. The version history and changelog describe every version.

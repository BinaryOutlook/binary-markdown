# Historical reference archive

This directory preserves superseded project materials for reference and inspiration. It is excluded from VSIX packages. The current installation, settings, and contribution instructions are in the root README and `docs/`.

## Upstream Any Markdown materials

`upstream-any-markdown/` preserves the presentation immediately before Binary Markdown's full naming realignment:

- `README.md`: prior README, including the outline-setting documentation from the local PR integration.
- `CHANGELOG.md` and `release_note/`: inherited Any Markdown release history.
- `docs/index.html`, `docs/images/`, `assets/`, and `media/`: prior website, screenshots, demo, and supporting artwork.
- `LICENSE`: original MIT license notice.
- `package.json`: the upstream manifest at commit `82487429`, retained for provenance and registration comparison tests.
- `build.sh`: obsolete machine-specific build helper; retained as history, not as a supported command.

Original branding, links, commands, release claims, and dates remain as historical evidence. They are not Binary Markdown release announcements or current setup instructions. See `SHA256SUMS` for the archived source-file checksums.

The original project is [raggbal/any-markdown](https://github.com/raggbal/any-markdown). Credit and license obligations remain in effect.

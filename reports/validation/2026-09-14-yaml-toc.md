```sh

npm run lint
npm run package
EXPORT_VSIX_PATH=dist/binary-markdown-0.2.0.vsix node --test test/unit/*.test.js
npm run test:build
CI=1 npx playwright test test/specs/document-aux.spec.ts test/specs/export-editor.spec.ts test/specs/command-palette.spec.ts test/specs/key-operations.spec.ts test/specs/pattern.spec.ts --workers=2 --retries=0
```

For native checks, follow [the isolated harness instructions](../../test/native/export-smoke.md) and use `--suite document-aux`. Raw native receipts and generated outputs remain local under `.vscode-test/document-aux/`.

## Scope

This validates the VS Code extension. The standalone Electron application was not validated: its separate dependency/type installation was unavailable. YAML is preserved as source, not validated against a schema. The TOC follows existing ATX headings and refreshes on Save or request. PDF page-numbered contents and sidebar bookmarks are not included. Other Markdown viewers may generate different heading anchors. See [the usage guide](../../docs/yaml-toc.md).

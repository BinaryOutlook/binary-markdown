## Current dependency audit

The initial 2026-10-07 `npm audit` against the unchanged dependency graph returned **five affected package findings: three high and two low**. They originate from three advisories; inherited findings for `serve` and `mermaid` are not additional independent vulnerabilities.

| Locked dependency | Scope | Advisory and patched version |
| --- | --- | --- |
| `compression` 1.8.1, inherited by `serve` 14.2.6 | Development server; both package findings are high | [Premature-response-close memory leak](https://github.com/advisories/GHSA-vc2v-76pw-4v95); compression 1.8.2 |
| `source-map-js` 1.2.1 | Development dependency through jsdom/css-tree; high | [Indexed source-map denial of service](https://github.com/advisories/GHSA-68fv-2mgg-jv7q); source-map-js 1.2.2 |
| `katex` 0.16.27, also used by `mermaid` 10.9.8 | Shipped math/diagram dependencies; both findings are low | [Existing prototype pollution can bypass trust restrictions](https://github.com/advisories/GHSA-238p-pmpm-9mq7); KaTeX 0.18.2 |

The KaTeX advisory requires an existing prototype-pollution condition; it does not establish an exploit in this extension. That audit blocked the repository's required candidate job, which runs `npm audit` without a severity exemption. [PR validation run 37565441002](https://github.com/BinaryOutlook/binary-markdown/actions/runs/37565441002) failed this step for the initial alignment commit; its native and browser matrices were skipped, not passed.

The initial documentation commits did not apply dependency fixes. `npm audit fix --force` proposed downgrades of Serve and Mermaid; those were not applied. The authorized follow-up pins direct KaTeX to 0.18.2 and overrides Mermaid's KaTeX dependency to the same package. It overrides Serve's pinned compression dependency to 1.8.2 and updates source-map-js to 1.2.2. All other package versions remain unchanged, apart from compression's added `destroy` 1.2.0 dependency. A clean root `npm ci` and `npm audit` passed with **zero findings** against this patched graph.

[KaTeX 0.17](https://github.com/KaTeX/KaTeX/releases/tag/v0.17.0) changed an internal extension API, which this application does not use. [KaTeX 0.18](https://github.com/KaTeX/KaTeX/releases/tag/v0.18.0) prefixed internal CSS classes. The project bundles matching renderer/CSS/fonts and uses stable outer KaTeX classes. Equation, Mermaid, editor-export and native equation checks therefore remain required for the replacement package; an audit pass alone does not prove rendering compatibility. A new trust regression verifies that inherited `trust` options do not authorize a JavaScript link. The accepted RC2's KaTeX 0.16.27 allowed that synthetic inherited option; patched KaTeX 0.18.2 rejects it. No application exploit is inferred from this controlled comparison.

## Diagnostic correction

The inspected main failure depended on browser-native Home/End behavior inside a noneditable diagnostic region nested in the visual editor. The corrected region handles unmodified Home/End itself, prevents the native action, stops propagation to the surrounding editor and scrolls immediately to its own boundary. Modifier-key combinations and ordinary pointer/arrow/page scrolling retain host behavior.

The browser regression now cycles End/Home three times and checks the boundary, retained panel focus, unchanged document scroll, unchanged Markdown, clean state and no new editing-activity notification. A controlled run with the previous handler behavior failed the new editing-notification assertion (one false edit report instead of zero); the corrected handler passed. This identifies an additional reproducible defect while removing reliance on the native animation that failed in hosted macOS Chrome. The full platform matrix remains authoritative for that environment.

## Focused acceptance checklist

Use synthetic documents or a backup, and record the exact candidate identity with each result.

- [ ] Move through Visual, Source and Split; edit and save, Undo/Redo, close and reopen. Confirm that source and current edits survive and that Split's preview is read-only.
- [ ] Find commands through the three-dot search, Action Palette and Insert workspace. Test narrow panes, keyboard navigation, Escape and retained insertion/selection locations.
- [ ] Search source with case, whole-word and regular-expression matching; replace selected matches and Undo once. Confirm that metadata and hidden syntax matches can be located in Source.
- [ ] Navigate a wide table, insert and undo rows/columns, resize the pane and change control placement. Check cell visibility and preservation of untouched table source.
- [ ] Copy long code with authored whitespace, toggle wrapping, switch views and save/reopen. Confirm exact source, visible wrap feedback and reset after reopening.
- [ ] Edit valid and invalid equations/diagrams, inspect diagnostics and scroll long details with keyboard and pointer. Confirm Home/End remain within the diagnostic panel and verify the patched math/diagram renderer against the replacement candidate.
- [ ] Exercise ordinary export and cancellation with the installed candidate; inspect representative HTML, PDF, DOCX and EPUB in actual readers. Record any carried-forward reader limits being accepted.
- [ ] Check an update from 0.4.1 retains settings, extension identity and default-editor associations; compare **Copy Build Information** with the candidate sidecar.
